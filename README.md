# ContainerLoader 装柜大师

3D 集装箱装柜计算软件 —— 多箱型混装、自动装载优化、PDF/Excel/HTML/PNG 报告导出。

基于 [手动装柜工具](https://zhangdezhi.ficp.fun/) 的设计理念，重构为桌面应用并叠加自动装箱算法。

![装柜大师](assets/icon.png)

## ✨ 功能

- **手动 3D 摆柜**：拖拽箱子、Q/E 旋转 90°、自动吸附（底面/顶面/侧面）、分层复制、六视图切换、自由视角
- **一键自动装载**：输入各箱型数量 → 算法自动分柜（体积/重量优先 + 最深最左最下 + 剩余空间分割 + 局部搜索迭代）
- **完整装箱优化（C 档）**：
  - 多箱型混装
  - 载重约束（每柜最大载重）
  - 承压约束（每箱型最大堆叠层数）
  - 多柜规划（自动逐柜分装）
  - **体积优先 / 重量优先** 双模式切换（重量优先按重箱先装，报告载重利用率）
  - **箱子旋转开关**：自动装载时可全局关闭旋转；单个箱型也可标记「禁止旋转」
  - 输出与**体积理论上界**的差距报告（3D 装箱 NP-Hard，算法为启发式逼近）
- **数据持久化**：箱型库/柜型库本地 JSON + 方案文件 `.cload`（含 `.bak` 自动备份）
- **CSV 导入箱型**：一键导入箱型库（名称,长,宽,高,重量,最大堆叠,颜色,可旋转），同名自动更新、非法行跳过
- **报告导出**：
  - 📄 PDF 方案报告（柜型参数、容积率、逐箱明细）
  - 📷 PNG 截图（当前视角 / 前左顶立四视图拼图）
  - 📊 Excel 装箱明细（总览 + 坐标/旋转/层明细）
  - 🌐 HTML 自包含报告（单文件，任何人可看）

## 🛠 使用

1. **左栏**配置箱型（长宽高/重量/堆叠层数/颜色/是否禁旋转）与柜型（内径/载重），支持自定义；可「导入 CSV 箱型」批量建箱
2. **自动装载**：右下角面板填写各箱型数量 → 选择「体积优先 / 重量优先」与「允许旋转」开关 → 点击「一键装载」→ 自动生成多柜布局（数量保留，方便改数重跑）
3. **手动调整**：拖拽箱子、选中按 Q/E 旋转、Delete 删除；「↑ 复制本层到上一层」快速堆叠
4. **导出**：顶栏 PDF/截图/Excel/HTML 按钮生成报告
5. **保存方案**：`.cload` 方案文件可保存/打开，下次继续编辑

### CSV 导入格式

表头（列名支持中英文别名，顺序不限）：

```
名称,长,宽,高,重量,最大堆叠,颜色,可旋转
纸箱 S,400,300,250,12,8,#4f9df7,是
中空板箱,900,600,500,60,4,,否
```

- 必需列：名称 / 长 / 宽 / 高；其余可省略（重量默认 0、堆叠默认 8、颜色默认蓝、可旋转默认允许）
- 同名箱型自动更新，新增箱型追加到库中

### 快捷键

| 按键 | 功能 |
|------|------|
| 左键拖拽 | 移动箱子（锁定状态自动吸附） |
| 右键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| Q / E | 选中箱子旋转 90° |
| Delete | 删除选中箱子 |
| 视图按钮 | 前/后/左/右/顶/立体六视图 |

## 🧰 开发

```bash
npm install
npm test        # packer 算法单元测试
npm start       # 开发运行
npm run dist    # 打包（electron-builder → dist/）
```

```
test/       packer + csv 单元测试
```
